Clawd Desk installer

Put Clawd Desk on your ESP32-2432S028R from the browser. No tools to install.

  1. Plug in the board

    Connect it to this computer with a USB data cable. Some cables only charge.

    Use Chrome or Edge on a computer. Other browsers can't talk to USB devices.

  2. Pick your board and install

    Not sure? Start with the first one. If the colors look like a photo negative afterwards, install again with the second.

    Board type
    This browser can't flash boards. Please open this page in Chrome or Edge on a computer. This page must be opened over https.

    Pick the port that says USB-SERIAL CH340 or CP210x. If it doesn't connect, hold the BOOT button on the back of the board and try again.

  3. Connect it to Wi-Fi

    When the screen says Wi-Fi setup, join the ClawdDesk-Setup network on your phone and pick your home Wi-Fi on the page that opens. If no page opens, go to 192.168.4.1.

  4. Set up your computer

    Windows: download and run the setup. It finds your screen, connects Claude Code and starts with Windows.

    Download ClawdDesk-Setup.exe

    Windows may warn that the app is from an unknown publisher. Click More info → Run anyway.

    macOS / Linux: see the guide on GitHub.
